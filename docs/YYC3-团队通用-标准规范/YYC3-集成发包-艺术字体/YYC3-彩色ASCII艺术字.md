### 方法3：使用 Python 脚本
```python
import re

def print_colored_ascii(file_path):
    with open(file_path, 'r', encoding='utf-8') as f:
        content = f.read()
    
    # 替换 ANSI 颜色代码
    content = content.replace('\\033[31m', '\033[31m')  # 红色
    content = content.replace('\\033[32m', '\033[32m')  # 绿色
    content = content.replace('\\033[33m', '\033[33m')  # 黄色
    content = content.replace('\\033[34m', '\033[34m')  # 蓝色
    content = content.replace('\\033[35m', '\033[35m')  # 紫色
    content = content.replace('\\033[36m', '\033[36m')  # 青色
    content = content.replace('\\033[0m', '\033[0m')    # 重置
    
    print(content)

print_colored_ascii('YYC3-AI-Family-Color.md')
```

- 绿色/黄色（中部）- 侧面
- 蓝色/紫色（下部）- 底面
- 青色（底部）- 基座
