## 核心功能

### 1. 彩色ASCII艺术字打印

支持6种ANSI颜色的艺术字输出：
- `\033[31m` - 红色
- `\033[32m` - 绿色
- `\033[33m` - 黄色
- `\033[34m` - 蓝色
- `\033[35m` - 紫色
- `\033[36m` - 青色
- `\033[0m` - 重置颜色

### 2. 文件读取功能

从外部文件读取并正确处理转义的ANSI颜色代码。

### 3. 预设示例集合

内置A、Y、C、3四个字符的彩色ASCII艺术字示例。

## A-Z字母设计规范

### 设计原则

1. **竖列格式**：每个字符使用6行文本表示
2. **彩虹渐变**：每行使用不同颜色（红→绿→黄→蓝→紫→青）
3. **等宽字符**：使用Unicode方块字符（█、╗、╝、╔、╚等）确保跨平台一致性
4. **居中对齐**：所有字符在同一垂直线上对齐

### 字符模板结构

每个字母遵循以下结构模式：

```python
'CHARACTER': [
    '\033[31m  第1行（红色）  \033[0m',
    '\033[32m  第2行（绿色）  \033[0m',
    '\033[33m  第3行（黄色）  \033[0m',
    '\033[34m  第4行（蓝色）  \033[0m',
    '\033[35m  第5行（紫色）  \033[0m',
    '\033[36m  第6行（青色）  \033[0m'
]
```

#### 批量生成ASCII艺术字

```python
def generate_word_art(word, character_dict):
    """
    生成单词的ASCII艺术字
    
    Args:
        word (str): 要生成的单词
        character_dict (dict): 字符字典
    
    Returns:
        list: 包含6行的单词ASCII艺术字
    """
    word = word.upper()
    result = [[] for _ in range(6)]
    
    for char in word:
        if char in character_dict:
            for i, line in enumerate(character_dict[char]):
                result[i].append(line)
    
    return [' '.join(lines) for lines in result]
```

### 4. 动态生成

```python
def generate_dynamic_ascii(text, colors=None):
    """
    动态生成文本的ASCII艺术字
    
    Args:
        text (str): 要生成的文本
        colors (list): 自定义颜色列表（6种颜色）
    
    Returns:
        str: 格式化的ASCII艺术字
    """
    if colors is None:
        colors = [
            '\033[31m', '\033[32m', '\033[33m',
            '\033[34m', '\033[35m', '\033[36m'
        ]
    
    text = text.upper()
    result = []
    
    for i in range(6):
        line_parts = []
        for char in text:
            if char in LETTERS:
                ascii_line = LETTERS[char][i]
                colored_line = ascii_line.replace('\033[31m', colors[i])
                line_parts.append(colored_line)
        if line_parts:
            result.append(' '.join(line_parts))
    
    return '\n'.join(result)
```

import platform

def get_terminal_color_support():
    """检测终端颜色支持"""
    system = platform.system()
    
    if system == 'Windows':
        # Windows需要特殊处理
        import ctypes
        kernel32 = ctypes.windll.kernel32
        kernel32.SetConsoleMode(kernel32.GetStdHandle(-11), 7)
        return True
    else:
        # Unix-like系统通常支持ANSI颜色
        return True

def safe_color_print(text):
    """安全的颜色打印"""
    if get_terminal_color_support():
        print(text)
    else:
        # 移除ANSI颜色代码
        import re
        clean_text = re.sub(r'\033\[[0-9;]+m', '', text)
        print(clean_text)

### B. 故障排除

#### 问题1：颜色不显示

**症状：** ASCII艺术字显示正常，但没有颜色

**解决方案：**
1. 检查终端是否支持ANSI颜色代码
2. 确保文件中的颜色代码格式正确（如 `\033[31m`）
3. 在Windows上，尝试启用ANSI颜色支持

#### 问题2：字符错位

**症状：** 字符对齐不正确

**解决方案：**
1. 确保使用等宽字体
2. 检查每行的长度是否一致
3. 验证Unicode字符的兼容性

#### 问题3：文件读取错误

**症状：** 无法读取文件或显示乱码

**解决方案：**
1. 确保文件编码为UTF-8
2. 检查文件路径是否正确
3. 验证文件权限
