## 关键经验沉淀

1. **Push Protection 是最后防线**：历史密钥（阿里云 AK）由 GitHub 拦截暴露，filter-repo 净化 + 强推闭环；文档示例一律占位符。
2. **托管环境假设须实测**：NAS（fnOS）无 docker CLI、SSH 非标端口 9557、MariaDB 为原生安装——方案设计前先探明。
3. **boot.js 是构建产物**：位于 `dist-server/`（`npm run build:server` 产出），仓库根无此文件；esbuild 自包含免 node_modules。
4. **后台进程需 nohup + disown**：普通 `&` 随终端回收导致「连接被拒」假象。
5. **家庭隐私资产隔离**：实拍照片不入公开仓库（f2af9bc），历史重写后引用层与对象层均已清除。
6. **三方对齐方向**：NAS git 停旧线时勿盲目 pull（会把照片带回合并结果），应强推新线 + 服务端 gc。
