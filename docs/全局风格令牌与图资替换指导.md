# YanYuCloudCube-MoChen 全局风格令牌与图资替换指导

适用项目：`/mnt/agents/output/app`（baby-growth-log 模板 · 个人专用版）
最近更新：2026-10-21 · 对应版本 ae7e87c

本文档解决两件事：

1. **设计令牌（Design Tokens）**：颜色、字体、圆角、阴影、动效等全局变量在哪里、当前值是什么、替换时的约束（对比度、深浅双主题成对修改）。
2. **全部图资的替换路径**：登录封面背景、Logo、四大模块背景、空状态插画、记录类型图标、点缀小图、家庭成员头像、字体文件——每一张图在哪个文件哪一行被引用、建议规格、替换后如何生效。

替换的统一 workflow 见文末「替换操作步骤」。所有路径均相对项目根目录 `/mnt/agents/output/app`。

### 1.3 替换主色时的硬约束（必读）

模板对主色有三档分工，**不要三档填同一个值**：

- `--accent`：纯面积，上面不压文字，可以用较亮/较饱和的颜色；
- `--accent-text`：小字色，与 `--bg`/`--panel` 的对比度必须 **≥ 4.5:1**；
- `--accent-solid`：按钮实底，与其上的 `--accent-ink` 对比度必须 **≥ 4.5:1**。

参考：原值 `#7c6bd6` 配白字只有 4.26:1 不达标，所以 text/solid 两档压深到 `#6a57c9`（5.5:1）。换成任何新主色都按同一逻辑反推。

## 二、登录封面（登录闸门页）

登录封面是应用打开时的闸门页（未登录 / 检查会话中显示），代码在 `src/main.jsx` 的 `GateScreen` 组件。

| 元素 | 引用位置 | 图资路径 | 原始规格 |
|---|---|---|---|
| **封面背景** | `src/main.jsx` 第 334 行 `landingbg` | `public/assets/scenes/hero-sky.jpg` | 1400×788，JPG |
| **封面罩层** | `src/styles.css` 第 935 行 `.landingveil` | 非图资：CSS 渐变 `linear-gradient(to bottom, rgba(246,246,247,.18), rgba(246,246,247,.52))` | — |
| **封面 Logo** | `src/main.jsx` 第 337 行 `landingmark` | `public/assets/logo.png` | 512×512，RGBA |
| 封面标题文案 | `src/i18n.js` 第 5 / 263 行 `brand` | 非图资：「YanYuCloudCube-MoChen」（zh / en 各一处） | — |

替换背景图：

1. 准备新图，**建议 ≥1920×1080、JPG、单张 ≤500KB**（封面全屏铺满，`object-fit: cover` 会裁切，主体请放在画面中下部，顶部会被标题区压住）。
2. 直接覆盖 `public/assets/scenes/hero-sky.jpg`（注意：**这张同时是今日页头卡的整幅背景** `src/views.jsx` 第 278 行 `SceneArt name="sky"`。若想封面与头卡用不同图，把新图放进 `scenes/` 后改 `src/main.jsx:334` 的 `src` 指向新文件即可）。
3. 若新背景色调变化大（如改深色照片），同步调整 `.landingveil` 的渐变颜色——它罩的是白纱，目的是压住背景让标题沉下来；深色底应改用黑纱，如 `rgba(16,16,18,.3) → rgba(16,16,18,.6)`。
4. 换 Logo：覆盖 `public/assets/logo.png`，保持透明底 RGBA 正方形。**该文件共 3 处引用**：登录封面（main.jsx:337）、桌面侧栏品牌标（main.jsx:1331）、宝宝头像缺省图（views.jsx:224）。换一张图三处同时生效；如想分离，改对应行的 `src`。

### 3.4 记录类型图标（glyphs，15 类）

`nursing（亲喂）· bottle（瓶喂）· diaper（换尿布）· pump（吸奶）· stock（存奶）· sleep（睡眠）· thermometer（体温）· ruler（身高）· capsule（用药）· plate（辅食）· juice（补充剂）· pencil（随手记）· camera（拍照）· sun（晒太阳/黄疸）· syringe（疫苗）`

### 3.5 点缀小图（spots，71 张）

映射表在同文件第 254–320 行，目录 `public/assets/spots/`，全部 `ill-*.png`（256×256 RGBA）。两类用法：

- **固定点缀**：`moonstars`（main.jsx:1351）、`sprig` / `stars` / `crib` / `frames` / `hearts` / `envelope`（views.jsx 多处）、`gift`（drawer.jsx:293）、`barchart`（chartview.jsx:337）。

## 四、替换操作步骤（统一 workflow）

```bash
cd /mnt/agents/output/app

# 1. 备份要覆盖的文件（可选但推荐）
cp public/assets/scenes/hero-sky.jpg /tmp/hero-sky.bak.jpg

# 2. 同名覆盖图资 / 编辑 src/styles.css、src/components.jsx 等
#    （设计令牌改动见第一节约束）

# 3. 重新构建（沙箱挂载偶发抖动，失败自动重试即可）
npm run build

# 4. 本地验证（生产模式冷启动）
node dist/boot.js   # 打开 http://localhost:3000
```

验证清单：

- [ ] 登录封面背景、Logo 显示正常，标题在罩层下仍清晰；
- [ ] 浅色 / 深色两主题各看一遍今日、图表、相册、家庭四页（设置里切换）；
- [ ] 替换主色后：主按钮白字、链接小字对比度可辨（有 Lighthouse 可跑 Accessibility 抽查，正文 ≥4.5:1）；
- [ ] 桌面 ≥1024px 与移动 375–430px 两宽度无横向滚动、图不错位；
- [ ] 替换 glyphs 图标后，15 类记录图标显示正常（加载失败会自动回落线描图标，不会白屏）。

## 五、注意事项

1. **深浅双主题成对改**：只改 `:root` 不改 `:root[data-theme="dark"]`（或反之）是高发事故。
2. **图资体积**：`scenes/` 背景图建议单张 ≤500KB、`spots/glyphs` ≤100KB；中文字体 woff2 已达 7.5MB，非必要不替换。
3. **文件名即契约**：`components.jsx` / `family.js` 里映射表按文件名找图，重命名文件必须同步改映射。
4. **安全网**：`SceneArt` 与 `TypeGlyph` 都有 `onError` 静默隐藏，图丢了页面不破——但别把安全网当规范，交付前跑一遍第四节验证清单。
5. **不改构建脚本与凭据**：`package.json` 的 build 脚本、`.env`、server 目录均为平台生成，风格替换不需要也不应触碰。
