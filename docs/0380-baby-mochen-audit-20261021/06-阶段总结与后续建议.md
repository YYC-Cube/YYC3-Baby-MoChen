## 五、后续建议

### 5.1 第一优先：把「能跑」变成「可回归」（对应 04 阶段 2）

| 序号 | 动作 | 验收 |
| --- | --- | --- |
| A-1 | 引入 ESLint（`eslint:recommended` + `react-hooks`）与 `npm run lint`，CI 0 error 阻断 | PR 合并前必须绿 |
| A-2 | Vitest 覆盖纯函数：`format` / `derive` / `charts`（跨午夜、空数据、单点）/ `family`（星座生肖边界）/ `exif` | 核心纯函数覆盖率 ≥ 80% |
| A-3 | `node:test` + MySQL service container 覆盖 `db.js` 首写 / 更新 / 冲突三态 | 409 返回 `current`，CI 真实执行 |
| A-4 | Playwright 冒烟 3 条：静态站进入应用、新增记录、刷新保留 | CI 通过并截图存档 |
| A-5 | 抽出 `scripts/assert-dist.mjs`（体积上限、敏感目录、`/api` 纯净性），CI 与 Pages 共用 | 两套 workflow 调同一脚本 |

> A-3 同时消解 02 文档中的「环境阻塞」：MySQL 用例一旦进 CI，冲突合并与照片缓存头就有了真实回归保护。

### 5.2 第二优先：安全与韧性收口（对应 01 文档 P2）

1. **静态响应头统一**：HTML/JS 补 `nosniff`、`Referrer-Policy`，评估最小 CSP（P2-01）。
2. **限流可信来源**：仅信任受控反代的 `X-Forwarded-For`（`TRUST_PROXY`），关键写接口加用户维度令牌桶（P2-02）。
3. **接口语义修正**：非法 JSON → 400、未知 API → 404、`signout` 非 POST → 405（P2-03 / P2-04）。
4. **服务端超时与优雅关闭**：`headersTimeout` / `requestTimeout`，SIGTERM 结束连接池（P2-05）。
5. **照片上传失败可见**：失败标记「未同步」+ 重试队列，避免静默丢图（P2-06）。

### 5.3 第三优先：性能与体验（对应 04 阶段 3）

1. **字体分片或改系统字体栈**：当前单文件 7.78MB 是首屏最大负担，目标 ≤ 1MB（P3-02）。
2. **拆分 `main.jsx`**：`useAuthGate` / `useSync` / `useTimer` / `useActions`，单文件 ≤ 600 行；由 A-1/A-4 保障行为不变。
3. **无障碍**：抽屉与灯箱补 Esc、`aria-modal`、焦点陷阱（P3-03）。
4. **同步状态可视化**：已同步/同步中/冲突/未同步常驻顶栏，不只靠 toast（事件维）。
5. **琐碎修正**：指标 ID 去非 ASCII（P3-01）、英文标题修正（P3-05）、结构化日志与 readiness 探针。

### 5.4 架构演进（按需，不建议提前投入）

`family_state` 行级化 + revision 增量同步 → 照片孤儿 GC → payload 契约（zod / JSON Schema）→ 导出备份与导入 → 趋势异常提示。触发条件：家庭记录量级上升、或多家庭 SaaS 需求确认。

## 六、运维与协作注意事项

1. **历史已重写**：任何旧克隆必须 `git fetch --all && git reset --hard origin/main`，禁止直接 merge；旧 SHA 引用会失效。
2. **GitHub 悬空对象**：force push 后旧提交在服务端回收前理论上仍可按旧 SHA 访问；需要绝对不可达时联系 GitHub Support 清理。
3. **Pages / CDN 缓存**：新部署已成功，但边缘缓存可能仍持有旧产物；发布后按需刷新 CDN 并核对 `index.html` 引用的 JS 哈希。
4. **家庭照片存放约定**：真实照片只放 `docs/assets/family/`（已 ignored），不进 `public/`、不入公开仓库；需要线上展示时走受控图片接口。
5. **远端构建环境**：`yyc3-22` 非交互 shell 的 node 在 `/opt/homebrew/bin/node`，远程执行 `npm run build` 需显式 PATH。
6. **GitHub 推送通道**：本地 HTTPS 不可达，推送经 `yyc3-22`（`git@github.com:`）中转，远端仓库为非 bare，需经临时分支 + `git reset --hard` 同步。
